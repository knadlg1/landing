3중 인증 시스템

확실한 출결 인증,
3중으로 철저하게

  • ① 본인 휴대폰 — 잠금 해제로 내 폰에서만 출결 가능
  • ② 카카오 계정 로그인 — 카카오는 스마트폰 1대만 로그인 가능, 대리 체크 불가
  • ③ 위치 확인 — 학생별 실습병원에서만 출결 승인, 반경 밖이면 출근 불가

주요 기능

국시원이 요구하는 실습 기준,
Here 하나로 모두 충족

본인 휴대폰 인증

잠금 해제로 본인 폰임을 인증. 타인 대리 체크 원천 차단.

카카오 계정 로그인

카카오는 스마트폰 1대만 로그인 가능. 별도 회원가입 없이 바로 시작.

실습병원 위치 검증

학생별로 배정된 실습병원 반경 내에서만 출결 승인. 반경 밖이면 버튼 비활성화.

실습 서류 자동 생성

실습인증 · 직권입력관리대장 · 수강증명서를 버튼 한 번으로 자동 출력.

담당자 서명 시스템

매주 병원 담당자가 앱에서 서명. 학생이 스스로 서명할 수 없어 신뢰도 확보.

원장님 전용 대시보드

학생 전체 출결 현황을 PC·모바일에서 실시간 확인. 지각·결석 즉시 알림.

시작 방법

복잡한 설치 없이
3단계면 됩니다

카카오톡으로 문의주시면 설치부터 사용법까지 직접 안내해 드립니다

1
카카오톡으로 신청

아래 버튼을 눌러 카카오톡으로 학원 정보를 알려주세요. 담당자가 바로 연락드립니다.

2
학원 설정 완료

실습병원 위치, 반 정보 등을 함께 설정해 드립니다. 10~15분이면 끝납니다.

3
학생 초대 후 시작

학생들에게 링크를 공유하면 카카오 로그인 후 바로 사용 가능합니다.
